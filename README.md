# مركز ؟

«شغل الفريق، واضح». مكتب عربي لفرق المشاريع الصغيرة: مهمة بمسؤول وموعد، مشروع يجمع قراراته وملفاته، وحركة الطماطة للتركيز الشخصي. الواجهة الرئيسية: **المكتب، مهامي، المشاريع**. القرارات والملفات داخل المشروع، والفريق والإعدادات في القائمة الثانوية.

## التشغيل

الموقع الثابت منشور عبر [GitHub Pages](https://salehkjj.github.io/markaz/) تحت `/markaz/`. الواجهة Next.js وTypeScript؛ الحسابات والبيانات والملفات الخاصة عبر Supabase. لا تُستخدم مفاتيح `service_role` في الواجهة.

1. طبّق ملفات `supabase/migrations` بالترتيب على مشروع Supabase جديد. مشروع الإنتاج `qeflgmknxuncpiycdulj` طُبقت عليه الترحيلات حتى `202610260004_decision_versions.sql` في 26 أكتوبر 2026. **لا تحذف الجداول الشخصية القديمة**؛ التطبيق لم يعد يعرض أدوات الدراسة، ويمكن لصاحب الحساب تنزيل أرشيفه من إعدادات الحساب.
2. اضبط Supabase Auth: Site URL هو `https://salehkjj.github.io/markaz/` وRedirect URLs تشمل `https://salehkjj.github.io/markaz/**` ورابط الاستعادة `https://salehkjj.github.io/markaz/?recovery=1`. فعّل البريد وكلمة المرور وتأكيد البريد.
3. محليًا انسخ `.env.example` إلى `.env.local`، وضع رابط المشروع والمفتاح العام publishable/anon، ثم `npm ci` و`npm run dev`. افتح `http://localhost:3000/markaz/`.
4. دفع `main` يشغّل [Pages workflow](.github/workflows/pages.yml): تثبيت نظيف، TypeScript، الاختبارات، اختبار قاعدة البيانات، تصدير ثابت، ونشر. إعدادات GitHub تحتوي مفتاحًا عامًا فقط.

## الدعوات والبريد

المالك ينشئ دعوة لبريد محدد؛ يظهر رابط للنسخ والمشاركة حتى عند فشل البريد. قبول الدعوة يتطلب حسابًا بالبريد **المؤكد والمطابق**، مرة واحدة، مع التحقق داخل قاعدة البيانات. رابط الدعوة يبقى في متصفح المستلم خلال الدخول وتأكيد البريد. يمكن إلغاء الدعوة وتجديد الرابط، فيبطل الرمز السابق. شاشة إنشاء الحساب تطلب اسم العرض من المستخدم.

الإرسال الآلي يمر عبر Edge Function `send-office-invite` ثم Supabase Auth. الوظيفة تتحقق من JWT وملكية المكتب ورمز الدعوة. لا يُعد قبول Auth لطلب الإرسال إثباتًا لوصول الرسالة. للاستخدام مع عناوين خارج أعضاء مشروع Supabase، يحتاج Auth إلى SMTP صالح. إعداد Gmail المجاني الممكن: `smtp.gmail.com`، المنفذ `465`، المستخدم وFrom `salehaljebr@gmail.com`، وكلمة مرور تطبيق Google من حساب المرسل. ضعه **في لوحة Supabase فقط** ضمن Auth → SMTP، ولا تضعه في GitHub أو المتصفح. ضع [عنوان الرسالة](supabase/email-templates/magic-link-subject.txt) و[قالبها](supabase/email-templates/magic-link.html) في Auth → Email Templates → Magic Link. لا تزال حالة SMTP والقالب ووصول بريد فعلي غير متحققة عبر الاتصال المتاح. الاسم المشتق من البريد في القالب مجرد تحية مقترحة، وليس اسم عرض مؤكَّدًا أو مصدر صلاحية.

## ما يفعله التطبيق

- مكتب باسم الفريق، مع مشروع أول وهدف أسبوع اختياريين. لا تُنشأ بيانات وهمية. إنشاء المشروع ثم المهمة ثم دعوة الزميل متاح من حالات الفراغ.
- أدوار مالك/مدير/نائب/عضو، بالمصفوفة [PERMISSIONS.md](PERMISSIONS.md). RLS والمشغلات ودوال قاعدة البيانات تمنع التصعيد والوصول إلى مكتب آخر. جميع أعضاء المكتب يرون جميع مشاريعه حاليًا؛ لا توجد خصوصية مستقلة لكل مشروع.
- المشاريع قابلة للأرشفة والاستعادة. المهام بقائمة أو لوحة، وبحث وفلاتر للصفوف المحمّلة، وتفاصيل وتعديل وتعليقات، مع كشف تعارض `updated_at` عند تعديل المهمة أو المشروع من جهازين. القرارات لها صاحب حسم وموعد ونتيجة؛ الاعتماد يتطلب نتيجة ويسجل من اعتمد ومتى، والقرار المعتمد لا يُعدّل صامتًا. تعارض تحرير موضوع معلّق يظهر بدل الكتابة فوق نسخة أحدث.
- ملفات خاصة وروابط داخل المشروع. يمكن إضافة نسخة جديدة من المرجع واعتماد نسخة واحدة حاليًا لكل مرجع، والنسخ السابقة محفوظة. التنزيل برابط موقّع مؤقت. حدود الملفات 20 ميغابايت وفق إعداد مساحة التخزين.
- حركة الطماطة: تركيز 25 دقيقة أو راحة 5 افتراضيًا، أو مدة تختارها، مرتبطة بمهمة أو حرة. الإيقاف والاستكمال والإلغاء والاستعادة بعد التحديث من حالة الخادم. الإنجازات والنقاط والستريك شخصية ولا تكمل المهمة تلقائيًا.
- روابط ثابتة بالمكتب/المشروع/تبويب القرارات أو الملفات/المهمة عبر query parameters، وعودة وتقدم المتصفح. بيانات الحساب والفريق محفوظة في Supabase؛ لا يوجد تعديل بلا اتصال. نسخة JSON من بيانات الحساب متاحة في الإعدادات، ولا تشمل محتويات الملفات الثنائية.
- حفظ المهمة أو المشروع أو القرار يحدّث القسم المتأثر وملخص المكتب فقط؛ حفظ الملف يحدّث المراجع فقط. عند تعذر تحديث العرض بعد كتابة ناجحة، تظهر حالة صريحة وزر تحديث يدوي. التحديث الدوري عند ظهور الصفحة كل 60 ثانية للمزامنة مع تغييرات الزملاء.

## الفحص والحدود

```bash
npm run typecheck
npm test
npm run test:db
npm run build
```

`test:db` يستخدم PGlite والترحيلات الفعلية لحسابات اختبار معزولة: الدعوة وقبولها، الأدوار والعزل، المهام والقرارات والتعليقات والملفات، ومنع تكرار مكافأة المؤقت. اختبر أيضًا ملخص المكتب بعد 120 مهمة وعزل إحصاء المستخدمين. الفحص المحلي لا يثبت وصول رسالة بريد فعلية، مزامنة جهازين حقيقيين، أو زمن شبكة Supabase في الإنتاج. الواجهة تجلب أحدث 100 سجل في القوائم ثم «المزيد»؛ **عدادات المكتب وأقرب تسليم** تُحسب من قاعدة البيانات كاملة حسب الصلاحية. قياسات الحجم والطلبات في [PERFORMANCE.md](PERFORMANCE.md)، وخطة تجربة خمسة فرق بلا تتبع خفي في [PILOT.md](PILOT.md). حدود Supabase وGitHub Pages المجانية تنطبق.
